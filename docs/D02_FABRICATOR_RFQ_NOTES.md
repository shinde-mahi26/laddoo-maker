# D02 Fabricator RFQ Notes

Status: **DFM review only — not released for fabrication**.

Please answer:

1. Are all proposed bends possible on available tooling?
2. What inside radius and bend allowance/K-factor will be used for each thickness?
3. Are any cutouts too close to bend lines?
4. Can the C-frame be fixture-welded and finish-machined after welding?
5. Which seams are most likely to distort?
6. Can wet-zone seams be continuously TIG welded, blended and passivated?
7. Can SS304 material certificates and contamination controls be provided?
8. Which changes would materially reduce prototype cost?
9. What dimensional inspection report can be supplied?
10. Can captive stainless hardware and non-collinear post-alignment dowels be supported?

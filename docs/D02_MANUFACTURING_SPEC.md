# D02 Manufacturing Specification — A01 Chassis

Status: **D02 DETAIL DESIGN — DFM REVIEW**. All parts are `PROTOTYPE_RELEASE_CANDIDATE` or explicitly `PROVISIONAL`; nothing is released for cutting.

SS304 thicknesses follow the authoritative schedule: base 2.0 mm; rear spine/deck/fascia 1.5 mm; sanitary wall 1.2 mm; exterior skins 1.0 mm; reinforcement 2.0 mm; C-frame 4.0 mm. General candidates: laser profile ±0.20 mm, formed dimensions ±0.50 mm, bend angle ±0.5°, welded chassis ±1.0 mm, finish-machined locating features ±0.10 mm, aligned AX_R ±0.15 mm.

Initial bend parameters are inside radius 2.0 mm and K-factor 0.42. These are quotation/DFM assumptions only and must be replaced with fabricator tooling data before cutting.

Wet-zone permanent seams use continuous TIG, blended sufficiently for cleaning, with heat tint removed and affected SS304 passivated by the fabricator's qualified process. Deburr and break all exposed edges. Prevent carbon-steel contamination.

The load path is A08 → common 4 mm C-frame → A07/base pads → reinforced foot mounts → countertop. Cosmetic covers, front door, fascia and sanitary partition are not alignment references.

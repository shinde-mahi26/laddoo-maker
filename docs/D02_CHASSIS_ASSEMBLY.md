# D02 Chassis Welding and Assembly

1. Laser cut preliminary profiles after bend-data approval; deburr.
2. Form base, spine, wall, deck and removable panels using common tooling.
3. Inspect formed parts before welding.
4. Fixture base and rear spine; tack using W4.
5. Measure diagonals/datums; apply balanced W2 structural weld sequence.
6. Fit sanitary wall/deck and apply continuous W1 wet-zone TIG seams.
7. Fabricate the C-frame separately: fixture, alternate tacks, verify, balance W2 welds.
8. Finish-machine critical C-frame interfaces after welding.
9. Install, align and dowel the C-frame using the documented procedure.
10. Add W3 dry-zone stitch welds for noncritical reinforcement where shown.
11. Blend wet-zone seams without excessive thinning; clean heat tint and passivate.
12. Install captive hardware, adapters, fascia, panels, door, inspection panel and feet.

W1: wet continuous TIG. W2: controlled structural TIG. W3: dry stitch weld. W4: fixture tack before verification/finish weld.
